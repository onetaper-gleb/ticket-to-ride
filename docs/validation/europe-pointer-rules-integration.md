## Pointer Lock: подтверждение и предел

Native click на canvas вернул `UnknownError`, `document.pointerLockElement=null`, публичное состояние `error`, cursor=auto. Первый клик не изменил выбор или фазу; Esc только освободил ввод и не открыл меню. Клавиатурные действия продолжили работать. В инвентаре доступны IAB и MCP Apps, настольного Chrome/Edge нет.

Нельзя считать successful mock state или CSS доказательством успешного системного захвата. Пользователю нужен следующий сценарий в настольном браузере, который разрешает Pointer Lock:

1. Откройте локальный URL в настольном Chrome/Edge. Продолжите текущую партию; закройте памятку через «Вернуться к игре».
2. Первый ЛКМ должен только захватить мышь, скрыть курсор и оставить билеты/карты неизменными. Двигайте мышь дальше края экрана: жесты продолжают переключать предметы.
3. Второй спокойный ЛКМ активирует текущий предмет. Удержание с движением больше 6 px, включая движение туда и обратно, не должно выполнить действие.
4. Esc освобождает мышь, оставляет фазу/вид и не открывает меню. Новый ЛКМ вновь только захватывает её.
5. Пробел освобождает мышь и открывает поле: обычный курсор, wheel/drag. Обратно пробелом; захват возвращается только после явного ЛКМ.
6. Проверьте освобождение при resize/переходе в другое окно/скрытии страницы и отсутствие скачка или старого клика после возврата.
