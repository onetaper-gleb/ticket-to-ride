# Навыки команды Europe

Проектные навыки лежат в `.agents/skills/`. Они применяются к текущему соло по классическим правилам Europe 2019. Глобальная конфигурация пользователя не меняется.

| Навык                                                       | Когда применять              | Основной контракт                                          |
| ----------------------------------------------------------- | ---------------------------- | ---------------------------------------------------------- |
| [lt-orchestrate](../.agents/skills/lt-orchestrate/SKILL.md) | Делегирование и интеграция   | Источники, владение файлами, общие типы и приёмка          |
| [lt-core](../.agents/skills/lt-core/SKILL.md)               | Правила, оплата и счёт       | Чистые переходы, точный путь, общие назначения станций     |
| [lt-bots](../.agents/skills/lt-bots/SKILL.md)               | Соло-боты и симуляции        | Честное Observation, легальные решения, партии на 2–5 мест |
| [lt-ui](../.agents/skills/lt-ui/SKILL.md)                   | Игровой интерфейс и обучение | Относительные жесты, отклик камеры, курсор поля и урок   |
| [lt-review](../.agents/skills/lt-review/SKILL.md)           | Независимая проверка         | Воспроизведение дефектов и отдельные доказательства правил |
| [lt-release](../.agents/skills/lt-release/SKILL.md)         | Выпуск текущего этапа        | Сборка, партия человека, сохранения и проверенный URL      |
| [lt-network](../.agents/skills/lt-network/SKILL.md)         | Будущий сетевой этап         | Серверное владение матчем и персональные наблюдения        |

Точные правила и пределы проверки данных находятся в [europe-rules.md](europe-rules.md). Процесс разработки — в [development.md](development.md). Навык направляет работу; легальность обеспечивает ядро.

При обновлении навыка проверяйте frontmatter и отсутствие незаполненных шаблонов через `quick_validate.py` из установленного skill-creator. Такая проверка не подтверждает качество решений агента. В отчёте различайте валидацию навыков, тесты движка, симуляции и реальные действия человека.
