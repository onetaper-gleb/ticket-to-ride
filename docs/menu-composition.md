# Статичная общая сцена меню

Ветка `design/menu-ticket-office-composition` объединяет полные истории environment geometry `25cc620f5c7b7a7053de3c7eb55934867063bfb9` поверх c919/788 поверх API `c4746fbe35c445cf1d1c9ac9f941e7f31c349c4e`, cashier `04766babc8132235fbc643ffee497ae4316c88fd` поверх e6 ticket/grip и art v4 + friends + print `82a61576330d3f279aadec45b964ffc4b31bde62` поверх runtime fdf0e67 от `bea9743`. Общий статичный кадр принимает оркестратор; затем compositor передаётся для production подключения. Desktop сходство — основной приоритет, narrow/compact проверены только как smoke. Production App, session, manifest и выпуск не меняются. Анимации остановлены до общей статичной приёмки. После нового указания владельца сходство всех элементов доводится итерациями; текущий кадр промежуточный. Обязательное правило проекта из `AGENTS.md`: только собственный код и публичный open-source стек, без Аркадии и внутренней инфраструктуры Яндекса.

## Загрузка и контакты

`createMenuComposition({ assetBase, signal })` загружает десять уникальных текстур, затем binary кистей до builders. Environment API c474 принимает optional surfaces/materialOverrides и возвращает actual именованные models.surfaces; новые base-color maps остаются собственностью caller, model kit владеет SRGB/repeating clones. Legacy wood/clock/stickers сохраняются, print materials отделены. Карты cream/green/boardPaint/wood/woodDark/leather/stone/paper связаны с шестью WebP: shared paint/wood не загружаются повторно. Stone повторяется 8×8 по UV большого пола, остальные карты 1×1; отдельные prints сохраняются. При ошибке Promise отклоняется; harness показывает статус. Отмена освобождает уже загруженные рисунки.

Согласованные точки — правая `(.10,0,.15)`, левая `(.35,0,.15)` в cashierAnchor-local. До builder настоящий marker правой руки переставляется через `cashierAnchor.localToWorld` и `contact.parent.worldToLocal` после обновления matrices. Затем оба реальных контакта окружения переводятся через `cashierAnchor.worldToLocal` ровно один раз для options builder. Его defaults не меняются. Кассирша стоит под anchor с identity transform. Три бумаги перенесены в настоящий `ticket-slot` с local offset `(0, .005, 0)`, identity quaternion и scale 1. Владение бумагами остаётся у cashier. Печать повёрнута на 90° в texture без изменения бумаги или хвата. Стрелки показывают 10:10 статично.

## Перспективная доска и native DOM

Desktop preset использует yaw 27°, камеру `(0.04, .52, 6.4)` и FOV 34°. Поворачивается `parts.stationRoot`: окно, прилавок, anchor кассирши, контакты рук, доска и часы. Environment root имеет identity transform; пол, багаж, фон и railway находятся вне stationRoot. Railway сохраняет world `(3.5,-.65,-3.1)` и identity orientation через обратное преобразование environment root. Train и platform сохраняют собственный yaw `-.65`. Мышь ракурс не меняет.

Новый пол уже находится на Y=-.90. Compositor размещает retained `outerCanopySupport` в local `(1.7,0,-.2)` внутри допустимой области кровли, `backdropRoot.x=2`. Стойка освобождает поезд, зелень остаётся за ним. Desktop часы `(2.114,1.55,-.03)` своим левым креплением X=-.414 опираются на эту стойку X=1.7. Лампы и их крепления сохранены из environment; новая компактная лампа отделена от головы. Геометрия частей не редактируется.

Левый задний чемодан стоит `(-2.4,-.9,2.1)`, освобождая settings. На desktop три левых чемодана получают дополнительный Z из `preset.luggageAdvance`: 0.8 в узле 1280, 0 в 1672/1920, с той же piecewise интерполяцией. Y и scale сохраняются; положение вычисляется из исходного snapshot, не накапливается при resize. Это удерживает багаж вне UI quad при более высокой доске 1280. Проверка использует консервативные projected convex hull реальных mesh vertices, включая ручки.

`layout(width, height, boardRect?, settingsRect?)` принимает **не трансформированные** внешние border boxes DOM. `x/y` — целевые координаты верхнего левого угла, `height` — высота левого края, `x + width` — горизонтальный ориентир правого края. Это ещё не итоговый экранный AABB. Края unproject на stationRoot-local плоскость фасада `z=.04`; Box3 передаётся в том же station-local space. Правый край становится ниже и короче по законам перспективы. Border 12/6 CSS px переводится в local units по левому краю. На desktop ориентиры выбраны по исходному PNG: board `(60, 50, 510, 596)`, settings `(125, 655, 390, 98)` при 1672×941. Narrow и compact сохраняют минимальные размеры.

`projectCorners(width, height)` проецирует новые world Vector3 из `board.getCorners()` в порядке TL, TR, BR, BL. Это bounding quad закруглённых физических рам на их front plane local Z=0, с transforms всех предков. Settings hangers находятся вне UI quad. `projectFrame` возвращает AABB этих четырёх углов для информационной диагностики. Передний quad проверен отдельно по XY bounds retained frame meshes; полный силуэт толщины может выступать за него.

`menuQuadCssMatrix(quad, width, height)` строит projective CSS `matrix3d` для **всей** доски: текст, фон и native кнопки получают ту же перспективу. Harness сначала снимает transform, измеряет border box, вызывает layout, берёт physical quad и применяет matrix с `transform-origin: 0 0`. После resize или изменения высоты DOM порядок повторяется. Не передавайте уже трансформированный `getBoundingClientRect` обратно в layout.

V4 desktop пресеты интерполируются отдельно между узлами 1280/1672/1920; общий scale предыдущей ревизии заменён. Board/settings: `(46,38,420,482)/(96,534,340,76)`, `(60,50,510,596)/(125,655,390,98)`, `(69,57,580,680)/(144,753,448,112)`. Поле `dom` возвращает размеры padding/header/rows/gaps/fonts/icons/mark/retry для native consumer. На 1672 header 136, row 94, label Times New Roman/Georgia 40/400, tutorial 28, settings 32, icon column 104, hint Plex 24, icon 44, mark 370; subtitle удалён. См. единственную `menu-ticket-office-design.md` принятого art commit.

Контракт art v4 сохраняет физические рамы на desktop. На desktop наружная доска сохраняет обычную высоту; native `.actions` ограничена оставшейся областью и прокручивается внутри. Ошибка остаётся рядом со своим слотом, retry 64px. Header/settings/3D рамы и подвесы видимы во всех десяти states; CSS border прозрачен. Высота viewport действий — 338/416/458 px в узлах 1280/1672/1920, padding 8px сохраняет focus ring. Прокрутка вертикальная с overscroll containment и полосой 8px. Retry связан с сообщением своего слота через `aria-describedby`. Tab/focusin, resize и изменения текста показывают активную кнопку через `scrollIntoView({ block: "nearest", inline: "nearest" })`. Длинные подсказки и коды не увеличивают внешнюю раму и не смещают settings. Own harness следует принятому контракту v4. Production CSS не меняется.

Canvas имеет `pointer-events: none` и `aria-hidden`. CSS border прозрачен: видна физическая 3D-рама, DOM фон ограничен padding box. Диалоги остаются native DOM вне перспективной доски. Четыре нулевых corner probes проверяют actual CSS transform независимо от экранного AABB.

## Ресурсы и проверка

Световой профиль compositor: hemisphere sky/ground `#bed0e2/#777a7c`, intensity 1.1; daylight `#fff2df`, intensity 1.5, position(6,8,2); мягкий RectArea fill `#fff1dd`, intensity 4, size5×4, position(2,3,4). Дневной свет справа создаёт диагональные тени на полу, fill смягчает свет на лице. Холодные нейтральные множители cream #c6cbd1/stone #a0adbe уменьшают общую жёлтую заливку текстур; тёплые лампы и train Spot сохраняются. Более сильный hemisphere и shadow intensity .8 снижают контраст большой диагональной тени, PCF radius8 смягчает её край. Green и iron не получают нового tint. Warm spotlights следуют настоящим retained fixtures и их `contact.height`; targets находятся в том же lamp-local space. Отдельный shadowless train Spot (#ffe2b1, intensity200/distance12/angle.3/penumbra.9) из (4,1.7,1.4) направлен в actual train-local boiler point(0,.95,.55) после каждого layout. Он сохраняет читаемость локомотива. Window spot даёт shadow1024², key shadow2048² с normalBias .004, radius8 и intensity .8. Камера, yaw, контакты и модельные transforms сохраняются. Three.js MIT LTC lookup tables общие для движка, инициализируются один раз; GPU uploads принадлежат renderer.

Own harness использует ACES/exposure1/DPR1, PCF shadows. Shadow maps обновляются один раз перед статичным render, не повторно во время normal pass. Pipeline: RenderPass → half-resolution SSAO24samples(radius.2/minDistance.0003/maxDistance.015) → два depth-aware Gaussian passes → OutputPass → FXAA. Color targets HalfFloat без MSAA; ненужный depth buffer у AO/blur выключен. Depth blur использует настоящий normal-pass depthTexture, защищает переходы глубины и сохраняет focal band4…10.5 scene units: ближний котёл, буферы и ходовая остаются резкими, дальше blur растёт на .9px/scene unit до max3px. Передний план ближе4 получает .5px/scene unit до того же предела. `?no-depth` и `?no-ao` служат контролями. Size/projection uniforms обновляются после camera/layout, physical DPR учтён. Native DOM остаётся резким и имеет прежнюю homography.

Post targets/passes принадлежат harness и освобождаются до renderer; lamp shadow/targets — compositor. Установленный SSAOPass пропускает `ssaoMaterial` и `noiseTexture` в своём dispose; harness освобождает их явно один раз. Общие LTC textures сохраняются до завершения renderer/context. MenuAO принимает full physical size от composer, устанавливает normal/depth в full resolution и только ssao/blur targets в половинное; width/height/DPR memo исключает лишний sizing при redraw. После двух обычных redraw проверено 0 create/deleteTexture и framebuffer, после двойного dispose все owned post targets/materials/noise освобождены один раз. Resize 1280→1920→1672 и DPR1→2→1 сохраняет framebuffer complete, half AO/full depth, точные projection uniforms и общий настоящий depthTexture. `dispose` идемпотентен: cashier освобождает бумаги, геометрию, материалы и skeletons; environment — свои meshes, материалы и texture clones; compositor — девять входных Texture и shadows. Harness освобождает renderer и listeners. Повторного общего dispose обхода bundles нет. Нет постоянного rAF, AnimationMixer или imports menu-animation; загрузка и изменения layout вызывают статичный redraw.

На checkpoint `976d20e` browser checks проверили native clicks у четырёх краёв пяти действий, Tab/focus-visible, Escape и возврат фокуса, reader правил и desktop resize. Контакты сохраняются при дополнительном parent translation/yaw/nonuniform scale. Реальная skin geometry и все sleeve/cuff meshes находятся минимум на Y≈.002; triangle clipping всех skin/cloth meshes с объёмом билета даёт 0 пересечений. Нижние skin points имеют ray hits настоящего прилавка. Кисти разделены, бумаги holder не пересекают пять стенок. На том же checkpoint после 20 layout и двойного dispose 257 ресурсов и два skeletons освобождены ровно один раз; pre-abort и abort binary освободили загрузку. Финальная дельта не меняет владение ресурсами; повторная проверка ограничена новой бумагой/хватом/UV и scroll/focus/resize desktop.

Четыре physical/DOM угла сравниваются отдельно от полного силуэта рамки. На desktop CSS probes отклоняются максимум на .038 px; независимая проверка quad по retained geometry — менее .000012 px.
