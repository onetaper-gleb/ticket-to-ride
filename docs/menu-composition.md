# Статичная общая сцена меню

Ветка `design/menu-ticket-office-composition` объединяет полные истории environment API `c4746fbe35c445cf1d1c9ac9f941e7f31c349c4e` поверх geometry `7bfee581e870b274769eb963d5033ebc710a3f51`, cashier `e6b8fc86f56420d7630c6fc1733215e6437fee94` и art v3.1 `a1ab201ee0d6122c32ac99f7adcfe42a55650be6` от `bea9743`. Общий статичный кадр принимает оркестратор; затем compositor передаётся для production подключения. Desktop сходство — основной приоритет, narrow/compact проверены только как smoke. Production App, session, manifest и выпуск не меняются. Анимации остановлены до общей статичной приёмки. После нового указания владельца сходство всех элементов доводится итерациями; текущий кадр промежуточный. Обязательное правило проекта из `AGENTS.md`: только собственный код и публичный open-source стек, без Аркадии и внутренней инфраструктуры Яндекса.

## Загрузка и контакты

`createMenuComposition({ assetBase, signal })` загружает четыре рисунка, затем binary кистей до builders. Environment API c474 принимает optional surfaces/materialOverrides и возвращает actual именованные models.surfaces; новые base-color maps остаются собственностью caller, model kit владеет SRGB/repeating clones. Legacy wood/clock/stickers сохраняются, print materials отделены. Новые committed карты ожидаются. При ошибке Promise отклоняется; harness показывает статус. Отмена освобождает уже загруженные рисунки.

Согласованные точки — правая `(.10,0,.15)`, левая `(.35,0,.15)` в cashierAnchor-local. До builder настоящий marker правой руки переставляется через `cashierAnchor.localToWorld` и `contact.parent.worldToLocal` после обновления matrices. Затем оба реальных контакта окружения переводятся через `cashierAnchor.worldToLocal` ровно один раз для options builder. Его defaults не меняются. Кассирша стоит под anchor с identity transform. Три бумаги перенесены в настоящий `ticket-slot` с local offset `(0, .005, 0)`, identity quaternion и scale 1. Владение бумагами остаётся у cashier. Печать повёрнута на 90° в texture без изменения бумаги или хвата. Стрелки показывают 10:10 статично.

## Перспективная доска и native DOM

Desktop preset использует yaw 27°, камеру `(0.04, .52, 6.4)` и FOV 34°. Поворачивается `parts.stationRoot`: окно, прилавок, anchor кассирши, контакты рук, доска и часы. Environment root имеет identity transform; пол, багаж, фон и railway находятся вне stationRoot. Railway сохраняет world `(3.5,-.65,-3.1)` и identity orientation через обратное преобразование environment root. Train и platform сохраняют собственный yaw `-.65`. Мышь ракурс не меняет.

Новый пол уже находится на Y=-.90. Compositor размещает retained `outerCanopySupport` в local `(1.7,0,-.2)` внутри допустимой области кровли, `backdropRoot.x=2`. Стойка освобождает поезд, зелень остаётся за ним. Desktop часы `(2.114,1.55,-.03)` своим левым креплением X=-.414 опираются на эту стойку X=1.7. Лампы и их крепления сохранены из environment; новая компактная лампа отделена от головы. Геометрия частей не редактируется.

Левый задний чемодан стоит `(-2.4,-.9,2.1)`, освобождая settings. На desktop три левых чемодана получают дополнительный Z из `preset.luggageAdvance`: 0.8 в узле 1280, 0 в 1672/1920, с той же piecewise интерполяцией. Y и scale сохраняются; положение вычисляется из исходного snapshot, не накапливается при resize. Это удерживает багаж вне UI quad при более высокой доске 1280. Проверка использует консервативные projected convex hull реальных mesh vertices, включая ручки.

`layout(width, height, boardRect?, settingsRect?)` принимает **не трансформированные** внешние border boxes DOM. `x/y` — целевые координаты верхнего левого угла, `height` — высота левого края, `x + width` — горизонтальный ориентир правого края. Это ещё не итоговый экранный AABB. Края unproject на stationRoot-local плоскость фасада `z=.04`; Box3 передаётся в том же station-local space. Правый край становится ниже и короче по законам перспективы. Border 12/6 CSS px переводится в local units по левому краю. На desktop ориентиры выбраны по исходному PNG: board `(60, 50, 510, 596)`, settings `(125, 655, 390, 98)` при 1672×941. Narrow и compact сохраняют минимальные размеры.

`projectCorners(width, height)` проецирует новые world Vector3 из `board.getCorners()` в порядке TL, TR, BR, BL. Это bounding quad закруглённых физических рам на их front plane local Z=0, с transforms всех предков. Settings hangers находятся вне UI quad. `projectFrame` возвращает AABB этих четырёх углов для информационной диагностики. Передний quad проверен отдельно по XY bounds retained frame meshes; полный силуэт толщины может выступать за него.

`menuQuadCssMatrix(quad, width, height)` строит projective CSS `matrix3d` для **всей** доски: текст, фон и native кнопки получают ту же перспективу. Harness сначала снимает transform, измеряет border box, вызывает layout, берёт physical quad и применяет matrix с `transform-origin: 0 0`. После resize или изменения высоты DOM порядок повторяется. Не передавайте уже трансформированный `getBoundingClientRect` обратно в layout.

V3.1 desktop пресеты интерполируются отдельно между узлами 1280/1672/1920; общий scale предыдущей ревизии заменён. Board/settings: `(46,38,420,482)/(96,534,340,76)`, `(60,50,510,596)/(125,655,390,98)`, `(69,57,580,680)/(144,753,448,112)`. Поле `dom` возвращает размеры padding/header/rows/gaps/fonts/icons/mark/retry для native consumer. На 1672 header 136, row 94, label Georgia 32/400, hint Plex 24, icon 44, mark 370; subtitle удалён. См. единственную `menu-ticket-office-design.md` принятого art commit.

Контракт art v3.1 сохраняет физические рамы на desktop. На desktop наружная доска сохраняет обычную высоту; native `.actions` ограничена оставшейся областью и прокручивается внутри. Ошибка остаётся рядом со своим слотом, retry 64px. Header/settings/3D рамы и подвесы видимы во всех десяти states; CSS border прозрачен. Высота viewport действий — 338/416/458 px в узлах 1280/1672/1920, padding 8px сохраняет focus ring. Прокрутка вертикальная с overscroll containment и полосой 8px. Retry связан с сообщением своего слота через `aria-describedby`. Tab/focusin, resize и изменения текста показывают активную кнопку через `scrollIntoView({ block: "nearest", inline: "nearest" })`. Длинные подсказки и коды не увеличивают внешнюю раму и не смещают settings. Own harness следует принятому контракту v3.1. Production CSS не меняется.

Canvas имеет `pointer-events: none` и `aria-hidden`. CSS border прозрачен: видна физическая 3D-рама, DOM фон ограничен padding box. Диалоги остаются native DOM вне перспективной доски. Четыре нулевых corner probes проверяют actual CSS transform независимо от экранного AABB.

## Ресурсы и проверка

Световой профиль compositor: hemisphere sky/ground `#bed0e2/#65503b`, intensity .7; daylight `#fff0d4`, intensity 2.2, position(6,8,2); мягкий RectArea fill `#ffe9c8`, intensity 3, size5×4, position(2,3,4). Дневной свет справа создаёт диагональные тени на полу, fill смягчает свет на лице. Два warm spotlights следуют настоящим retained fixtures и их `contact.height`; targets находятся в том же lamp-local space. Window spot даёт shadow1024², key shadow2048² с normalBias .004 и radius5. Камера, yaw, контакты и модельные transforms сохраняются. Three.js MIT LTC lookup tables общие для движка, инициализируются один раз; GPU uploads принадлежат renderer.

Own harness использует ACES/exposure1/DPR1, PCF shadows. Shadow maps обновляются один раз перед статичным render, не повторно во время normal pass. Pipeline: RenderPass → half-resolution SSAO24samples(radius.2/minDistance.0003/maxDistance.015) → два depth-aware Gaussian passes → OutputPass → FXAA. Color targets HalfFloat без MSAA; ненужный depth buffer у AO/blur выключен. Depth blur использует настоящий normal-pass depthTexture, защищает переходы глубины и сохраняет focal band6±2 scene units; max blur3px. `?no-depth` и `?no-ao` служат контролями. Size/projection uniforms обновляются после camera/layout, physical DPR учтён. Native DOM остаётся резким и имеет прежнюю homography.

Post targets/passes принадлежат harness и освобождаются до renderer; lamp shadow/targets — compositor. Установленный SSAOPass пропускает `ssaoMaterial` и `noiseTexture` в своём dispose; harness освобождает их явно один раз. Общие LTC textures сохраняются до завершения renderer/context. HalfResolutionAO принимает full physical size от composer и устанавливает AO targets сразу в половинное разрешение; width/height/DPR memo исключает лишний sizing при redraw. После двух обычных redraw проверено 0 create/deleteTexture и framebuffer, после двойного dispose все owned post targets/materials/noise освобождены один раз. Resize 1280→1920→1672 и DPR1→2→1 сохраняет framebuffer complete, половинное AO, точные projection uniforms и общий настоящий depthTexture. `dispose` идемпотентен: cashier освобождает бумаги, геометрию, материалы и skeletons; environment — свои meshes, материалы и texture clones; compositor — четыре входные Texture и shadows. Harness освобождает renderer и listeners. Повторного общего dispose обхода bundles нет. Нет постоянного rAF, AnimationMixer или imports menu-animation; загрузка и изменения layout вызывают статичный redraw.

На checkpoint `976d20e` browser checks проверили native clicks у четырёх краёв пяти действий, Tab/focus-visible, Escape и возврат фокуса, reader правил и desktop resize. Контакты сохраняются при дополнительном parent translation/yaw/nonuniform scale. Реальная skin geometry и все sleeve/cuff meshes находятся минимум на Y≈.002; triangle clipping всех skin/cloth meshes с объёмом билета даёт 0 пересечений. Нижние skin points имеют ray hits настоящего прилавка. Кисти разделены, бумаги holder не пересекают пять стенок. На том же checkpoint после 20 layout и двойного dispose 257 ресурсов и два skeletons освобождены ровно один раз; pre-abort и abort binary освободили загрузку. Финальная дельта не меняет владение ресурсами; повторная проверка ограничена новой бумагой/хватом/UV и scroll/focus/resize desktop.

Четыре physical/DOM угла сравниваются отдельно от полного силуэта рамки. На desktop CSS probes отклоняются максимум на .038 px; независимая проверка quad по retained geometry — менее .000012 px. Геометрический color pass без теней/post сохранил 99 calls; scene geometry: 91 918 triangles, 97 unique geometry, 34 materials, два skeletons; vertex/index arrays 9 960 492 bytes. Четыре используемые карты оцениваются в 3 844 781 bytes RGBA с mipmaps, без bone textures/shadow/render targets. Load/build включает art HTTP, binary decode и builders; layout/GPU upload/shader compile не включены. Точные samples приложены к handoff. Для нового света/post измерены только 12 warm GPU draws через `EXT_disjoint_timer_query_webgl2` в публичном Chromium151/ANGLE Metal AppleM4Pro, без disjoint. Default depth+AO:359calls/352511tri включая тени и normal pass; без post:253calls/260586tri. Render-target estimate48,785,616bytes≈46.5MiB без shadow/LTC/default framebuffer/driver overhead. Точные CPU/GPU samples — `menu-render-cost.json` в handoff; это не FPS и не стоимость DOM/layout/presentation. Production lifecycle menu→game этим статичным harness не проверяется.

Принятые revisions исправили размер головы/плеч, положение руки, нижний фасад/пол, массы багажа, котёл/платформу, опоры, лампы, интерьер и v3 оформление доски. Принятая бумага e6b8fc8 имеет coordinated ticket geometry и ticketGrip; compositor их отдельно не вращает. В текущем ракурсе она около 63×88 px против примерно 60×90 px в исходнике. Фактуры и силуэты моделей остаются проще PNG; точное визуальное сходство пока не принято. Новые owner tips подключаются только после фиксации и передачи оркестратором.

Неблокирующее ограничение compact smoke: при 800×600 settings выходит до document Y≈641, а raster canvas остаётся высотой 600. После внешнего scroll нижние ≈41px физической рамки обрезаны; native settings доступна и dialogs работают. Desktop с внутренним actions scroll этого ограничения не имеет. Дальнейшая адаптация не входит в текущую приёмку по просьбе пользователя.
