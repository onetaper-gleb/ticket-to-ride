# Меню «Билетная касса»: производственная спецификация

Версия 2, 10 октября 2026. Единственная актуальная спецификация для сверки реальных моделей. Выбран вариант 2. База ветки `design/menu-ticket-office-art` — `bea9743c7622a7806a3d9b6824a9d912b0a41b65`; это локальный интеграционный снимок, не выпущенная версия. Документ задаёт CSS-композицию. Окружение переводит её в Three.js и проверяет проекцию. DOM и модели соединяет интегратор.

## boardRect и settingsRect

Все координаты в CSS px от верхнего левого угла viewport. `boardRect` — внешняя граница физической рамы, не область текста. Рама 12 px по каждой стороне; внутреннее дерево/металл не нависает над DOM. Непрозрачная плоскость начинается с inset 12 px. Контент начинается с inset 24 px (на большом desktop — 28 px). Settings — отдельная рамка 6 px с контентом inset 12 px.

| 1280×720 | desktop | 48,84,420,454 | 64,562,388,64 | 88 / 72 / 6 | 22 px / 1.2 |
| 1920×1080 | desktop | 128,174,540,500 | 144,698,508,72 | 100 / 76 / 8 | 26 px / 1.2 |
| 900×1000 | narrow | 32,272,400,470 | 48,766,368,64 | 80 / 72,72,96,72 / 6 | 22 px / 1.2 |
| 800×600 | compact | 24,40,360,438 | 40,498,328,56 | 80 / 64,64,88,64 / 6 | 20 px / 1.2 |
| 2560×1080 | ultrawide | 448,174,540,500 | 464,698,508,72 | как 1920 | 26 px |
| 3440×1440 | ultrawide | 888,200,540,500 | 904,724,508,72 | как 1920 | 26 px |

Заголовок — высота строки блока, затем 12 px gap (16 на большом desktop). Он содержит собственный знак EUROPE и доступный DOM h1 «Ticket to Ride: Europe». Иконка 32×32, столбец 40 px; gap иконка/текст 12 px. Горизонтальные отступы строки 12 px. Пояснения 20 px с line-height 1.2; высота строки растёт, если контент не помещается. Размеры таблицы — минимумы, а не clipping box. Длинная подпись обучения переносится на два ряда в narrow/compact/column; третья строка зарезервирована выше остальных во всех состояниях этих presets. В desktop подпись помещается в одну строку, пояснение — во вторую.

Desktop применяется при width ≥1100 и height ≥680. `t = clamp((min(width,1920)-1280)/640,0,1)`: width = 420+120t; header = 88+12t; row = 72+4t; gap = 6+2t; content inset = 24+4t. Высота = 454+46t. x = max(0,(width-1920)/2)+48+80t; y = clamp(40,height/4-96,200). Settings x = board.x+16, y = board.bottom+24, w = board.w-32, h = 64+8t. При width>1920 это ultrawide с центральной рабочей областью 1920 px.

Narrow применяется при 760≤width<1100, height≥760 и aspect<1.25. x=32, y=clamp(220,height×0.272,360), w=min(400,width-64). Остальные окна width≥760 — compact. При width<760 — column, x=16, y=24, w=min(360,width-32). У compact и column settings y=board.bottom+20, вертикальный padding таблички 6 px. Во всех presets документ получает min-height=settings.bottom+32 и вертикальную прокрутку. При любой высоте ошибки и строки могут увеличить его. Горизонтальный скролл отсутствует; текст/коды `overflow-wrap:anywhere`, flex-child `min-width:0`. Browser zoom меняет CSS viewport и выбирает preset заново; font-size не масштабируется скриптом.

## frameBounds и печать для 3D владельцев

`frameBounds` в экранной системе равен внешнему `boardRect`; aperture = `(x+12,y+12,w−24,h−24)`, DOM content = `(x+24,y+24,w−48,h−48)` на обычном/compact/narrow, inset 28 на большом desktop. Settings frameBounds = settingsRect, aperture inset 6, content inset 12. Внешний радиус угла 8 px, внутренний 3 px; кант 1 px; головки заклёпок 9 px внутри 12 px полосы. Face/hand safe zones считают от внешней границы, включая раму. World размеры получаются unproject этих прямоугольников на выбранную глубину; `board.bounds` и `settingsBounds` содержат внешнюю геометрию, а не только печатную плоскость. Толщина по Z — рекомендация 0.04 world units, без выступов поверх aperture; согласовать по реальному общему кадру. Ошибка увеличивает высоту `boardRect`; `settingsRect` сдвигается вниз, сохраняя размеры, если его собственный текст не переносится. Рама получает новые размеры после измерения, без фиксированной высоты старого blockout.

| Рисунок | Применение без растяжения |
| --- | --- |
| clock-face 512² | Квадратная UV, круг не превращать в овал. 12 сверху (+Y), лицевая сторона +Z. Rasterize 512²; отдельные стрелки в центре, artwork не поворачивать со стрелками. Поля 16 px прозрачны. |
| ticket-print 512×256 | Бумага ширина:высота 2:1. Для портретного билета повернуть весь Mesh бумаги на 90° с неизменёнными локальными UV; если бумага сразу строится 1:2, повернуть только UV на 90°. Выбрать один способ. Сохранять равномерный scale и весь рисунок; не растягивать под произвольный прямоугольник. |
| luggage-stickers 512² | Каждый crop 224² отображается квадратом. Одну эмблему на видимой плоской стороне чемодана, ширина около 30–40% ширины стороны; отступ до шва/ремня ≥5% ширины стороны. Наклейка не выступает над settingsRect. |
| wood-tile 256² | Repeat, волокна по X источника; для вертикальной детали повернуть UV целиком на 90°. Один общий цветовой tile, без дополнительного bump/normal в П1. |

Canvas crop использует верхний левый origin из таблицы. При загрузке всего atlas UV используют нижний левый origin. Верх каждой эмблемы направлен к +Y предмета. Владелец texture проверяет ориентацию одного тестового кадра; не применять одновременно ручной flip и повторный flip texture. Для парового A11 wiring и preview пока закрыты.

Зазор board.right до лица ≥48 px. Ни рука, ни билет, ни пар не пересекают boardRect/settingsRect. Чемоданы не заходят в левую область выше settings.bottom+16. Лицо сохраняется целиком; в narrow разрешено убрать вагон и дальний реквизит. Компактный crop не требует полного состава. На ultrawide добавляется платформа по краям; единый scale моделей не меняется по X.

Оси мира: +Y вверх, +Z к зрителю. Прилавок `cashierAnchor` Y=0; shoulders≈0.9 world units, верх головы≈Y1.1; проём 1.4–1.7 ширины плеч. Рабочая рекомендация FOV 34–38° вертикальный, без roll и DOF; перспективная глубина создаётся кассой/поездом. Доска screen-parallel (yaw/pitch относительно камеры 0°, максимум 1° после проверки). Относительная дистанция: board plane 0.88×distance к лицу, арка около 1×, поезд 1.65–2×. Настройки лежат в той же плоскости, что рама. Эти отношения уточняет владелец окружения, не масштабируя кассиршу по одной оси.

На resize CSS измеряет rect, MenuScene размещает раму на согласованной глубине unproject четырёх углов. `board.bounds`/`settingsBounds` — внешние Box3; внутри плоскость с inset 12/6 px. Допуск round-trip ≤2 CSS px. В column/scroll рама — CSS; живой декор не должен следовать прокрутке. Камера статична между resize; boardRect не зависит от часов/персонажа. Показанный кадр ещё не доказывает синхронизацию production сцены.

## Действия и состояния

Всегда четыре строки: «Продолжить», «Начать партию», «Обучение» либо «Продолжить обучение», «Правила». Затем «Настройки партии». No-save: продолжение disabled + «Нет сохранённой партии», янтарный акцент на новой партии; у обучения «До первого маршрута». Current: акцент продолжения, «Обычная партия». Tutorial: обычное продолжение disabled; учебное доступно с «До первого маршрута». Both: обе строки доступны независимо. Finished current: «Продолжить» + «Открыть итоги». Loading каждого слота: его действие disabled, «Проверяем сохранение…»; правила и форма доступны. Preparing game: «Готовим стол…», команды старта disabled; отдельный возврат при долгой загрузке. Error каждого слота: «Не удалось проверить сохранение» и отдельная DOM-кнопка «Повторить проверку» у этого слота; неизвестный слот не подписывается как пустой.

Error занимает место ниже соответствующей строки и увеличивает высоту доски; остальные действия сдвигаются вниз вместе с settingsRect. Сообщение никогда не заменяет label. Retry ≥52 px. Декоративный арт не содержит названий действий или статуса. Gallery показывает состояния данных отдельно от реальной session/storage.

Обычная строка: paper на row; primary: ink на accent. Hover: paper на hover, primary ink на paper. Press: primary ink на pressed, обычная paper на board; сдвиг ≤1 px. Disabled: disabled на board, без общей opacity. Focus: двойной контур ink 2 px + focus 3 px с зазором 3 px, видимый вокруг primary и обычной строки. Focus и hover могут сосуществовать; primary не получает keyboard focus автоматически. Reduced motion: мгновенный цвет, без сдвига. Длительность цвета 140 ms — рекомендация будущему этапу после принятия общего статичного кадра; текущая gallery переключает состояния мгновенно, без движения.

## Форма и правила

«Начать партию» и «Настройки партии» открывают один dialog «Параметры новой партии». Width=min(640px,viewport-32px), max-height=viewport-32px, overflow-y:auto. Бумага paper, текст ink, поля белые, граница row; body overlay `#172B25` с opacity0.66. Заголовок 28 px (compact24), обычный текст/labels20px. Кнопки/поля≥52px; padding24px (compact16). Все футеры в потоке; старт достижим прокруткой.

Поля: «Всего мест» 2/3/4/5 + «1/2/3/4 бота»; «Сложность ботов» Лёгкие/Обычные; «Ваше имя» maxlength24, default«Вы»; details «Код партии (необязательно)», maxlength64. Начальный размер3; выбранная сложность сессии. Пустое имя→«Вы», seed trim. «Назад» закрывает без запуска. «Сесть за стол» — единственный запуск. При current подпись «Сесть за стол — новая партия» и «Новая партия заменит обычное сохранение. Обучение сохранится». При unknown slot — предупреждение о возможной замене. Focus trap, Escape, возврат focus задаёт функциональщик.

«Правила» открывают существующий reader `src/ui/rules-pages.ts`, width=min(680px,viewport-32px), max-height=viewport-32px, внутренний scroll. Gallery использует существующий текст/иллюстрацию только для проверки размещения: это не новый дизайн памятки. «Назад», «Следующий лист», «Вернуться в меню» видимы/достижимы; черновик формы сохраняется.

## Порядок передачи

Ранняя спецификация e1ecaa4 заменена этой версией. Оба 3D владельца сверяют реальные модели по одному финальному candidate этой ветки. Интегратор собирает статичный menu-preview с настоящей кассиршей и окружением, артом и DOM. Галерея на draft-фоне подтверждает только DOM-компоновку. Анимации не запускаются до отдельного поручения после принятия общей статичной сцены. Уже созданный A11 сохраняется как неактивный П2 материал. UI, App/Diorama, manifest и production camera код эта ветка не меняет.

## Арт и проверки

П1 арт готов: A01 icons/{continue,start,tutorial,rules,settings}.svg; A02 europe-mark.svg; A03 board-paint.webp + lossless PNG; A05 clock-face.svg; A06 ticket-print.svg; A07 luggage-stickers.svg; A08 wood-tile.webp + PNG; A10 distant-sky.svg optional. Все пути внутри public/menu/art. A04 — динамический HTML/CSS из отдельной gallery; A09 — палитра материалов выше. A11 steam-mask-p2.png изготовлен, но П2 выключен. A12 fallback-draft-wide.webp1280×720 и fallback-draft-compact.webp720×960 — draft, замена кадром принятой 3D сцены остаётся у интегратора.

SVG исходники редактируемы. Периодические tiles и alpha mask воспроизводятся sources/generate-textures.py. inventory.json содержит байты, размеры, SHA256 и происхождение каждого файла; provenance.md — права, exact prompts генерации и способы применения. Иконки и знак вставлять inline либо CSS mask для currentColor. Рисунок билета 2:1; для портретной ориентации выбрать один поворот Mesh либо UV по правилу выше. Циферблат без стрелок, 12 сверху. Атлас наклеек: crops 224² origins 16,16 /272,16 /144,272. За загрузку и texture disposal отвечает bundle модели.

Runtime SVG+растр 133441 байт; растр 118828 байт с обоими fallback. Каждый fallback меньше 400 КБ. Консервативная оценка всех scene textures и обоих fallback в RGBA с mipmaps —14.953125 МиБ; без fallback/П2 —6.666667 МиБ. DOM SVG не переводятся в GPU textures. Render targets/shadows/PMREM в эту оценку не входят. Это расчёт размеров, не замер renderer.info.

Проверены реальные DOM rect на 1280×720,1920×1080,900×1000,800×600,2560×1080,3440×1440: размеры таблицы совпали, горизонтальный overflow отсутствует. На 800×600 rows64/64/88/64px, текст20px. На 640×360 CSS viewport показаны full-page макет и достижение настроек через Tab с прокруткой. Это макет эффективного viewport при 200%, а не подтверждение настоящего browser zoom: In-app Browser не изменил масштаб по Cmd+Plus (viewport/DPR остались1280×720/1). Настоящий zoom200% остаётся интеграционной проверкой.

Проверены no-save/current/tutorial/both/finished/loading/error-current/error-tutorial/error/preparing, disabled/hover/focus/pressed. Повторные старты в preparing недоступны, возврат виден. Независимое read-only ревью исправило: compact settings margin/padding, safe face gap и crop A12. Текстовые пары≥6.25:1; focus использует два контрастных контура. В формах проверены длинное имя/seed, scroll, существующая памятка, сохранение черновика и возврат focus/Escape. Gallery — демонстрация дизайна, не проверка реальных saves/игры.

Ограничения: A12 иллюстрирован и не повторяет final character/scene; на ultrawide видны границы draft-слоя. Нет измерений FPS/сборки 3D/scene round-trip/lifecycle или общей игровой регрессии. Production UI, камеры, manifest, main и Sites не менялись.
