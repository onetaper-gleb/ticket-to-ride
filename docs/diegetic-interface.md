# Управление через 3D стол — архив эвакуационной версии

Этот документ описывает интерфейс до перехода на Europe. Зоны мыши и приближение поля сохранены, но задания, приказы, ремонт, волны и фазы ниже больше не используются. Текущие контракты находятся в [архитектуре Europe](architecture.md), а обучение — в [onboarding.md](onboarding.md).

`TableView` содержит текст, доступность предметов, задания и маршрут. `TableInteraction` передаёт намерение; команды, расходы, движение и очки проверяет ядро. Сцена получает только `Observation`.

## Режимы ввода

За столом курсор скрыт. Большая область экрана выбирает коллекцию, приближает её и закрепляет одну опцию. Попадать в геометрию карты не требуется. Движение на 64 пикселя переключает соседнюю опцию; небольшие движения накапливаются. Камера внутри области неподвижна. Границы имеют запас 3,5% для защиты от дрожания.

| Область         | Опции                                                              |
| --------------- | ------------------------------------------------------------------ |
| Слева           | Пять открытых материалов и закрытая колода, сетка 2 × 3            |
| Снизу слева     | Районные задания, один ряд                                         |
| Снизу по центру | Своя рука, один ряд; пустая рука показывает «Материалов нет»       |
| Справа          | Печати листа, два столбца; без действий выбран сам лист для чтения |
| Снизу справа    | Звонок и книжки управления                                         |

ЛКМ активирует закреплённую опцию. При первом входе выбран доступный предмет; недоступные можно осмотреть, но нельзя активировать. Опция запоминается по ID. После удаления карты выбирается ближайшее оставшееся место. На краю ряда выбор остаётся на последней опции.

В центральной области ЛКМ или пробел открывает приближённое поле. Видимый курсор выбирает рельсы, станции и поезда через raycast. Предметы стола здесь не перехватывают нажатия. Пробел или Escape возвращает к столу; Escape за столом открывает меню. Книжка «Поле · Пробел» также переключает режим.

Tab фокусирует предмет и соответствующую область. Стрелки переключают опцию области, Enter активирует её. При фокусе станции, линии или поезда открывается поле. Меню и запасной интерфейс без WebGL используют обычные кнопки.

## Фазы и предметы

| Фаза       | Ввод и результат                                                                                                                                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `setup`    | Отметить два задания в нижней левой области, затем нажать печать «Принять задания» справа.                                                                                                                               |
| `action`   | Карта рынка или колода начинает добор. На поле первое нажатие по рельсу или своему поезду показывает цену; повторное оплачивает ремонт или экспресс. Звонок «Сохранить материалы» пропускает действие.                   |
| `draw`     | Взять второй материал. Открытая универсальная недоступна. Осмотр поля не прерывает добор.                                                                                                                                |
| `discard`  | Поле закрывается; рука поднята и остаётся активной независимо от положения мыши. Выбрать карту движением и нажать ЛКМ, повторять до десяти карт. Пробел не открывает поле во время сброса.                               |
| `orders`   | На поле: свой поезд → станция погрузки → убежище → повторное нажатие убежища. Загруженный поезд выбирает только убежище. На листе: режим позиции, повтор, отмена, остановка и подтверждение риска. Звонок завершает ход. |
| `finished` | Меловая доска показывает очки. Итоговый лист содержит группы и места бригад, печать запускает новую операцию.                                                                                                            |

Опасный рейс требует отдельной красной печати и повторного нажатия конечной станции. Смена поезда, цели, убежища, режима или повторения сбрасывает согласие. Ожидание ремонта подписано отдельно и не получает ложный срок прибытия.

## Защита жестов и приватность

Нажатие хранит режим, доступность и ревизию матча. Отпускание после смены ревизии, другой цели, отмены либо движения больше шести пикселей не активирует предмет. Перетаскивание может менять визуальный выбор, но не выдаёт команду. Звонки пропуска и конца хода стоят отдельно.

Материалы соперников показаны только рубашками по публичному количеству карт. Геометрия, текстуры и материалы освобождаются при перестройке и завершении сцены. Процедурные персонажи описаны в [направлении](characters.md).

## Референсы и проверка

Принцип информации на физических предметах опирается на авторское описание Buckshot Roulette: «diegetic systems and minimal UI». Конкретные области, закреплённый выбор и относительные движения — решения Last Train. [Страница Mike Klubnika](https://mikeklubnika.itch.io/buckshot-roulette).

[Приёмка предыдущего этапа](validation/diegetic.md) сохраняет его фактические результаты. [Приёмка зон](validation/zones.md) описывает текущую проверку мыши, клавиатуры, сохранения и полного матча.
