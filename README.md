# Ticket to Ride: Europe за 3D столом

Браузерная игра для ПК по классическим правилам Ticket to Ride: Europe 2019: один человек и 1–4 бота, всего 2–5 игроков.

Собирайте карты вагонов, занимайте маршруты и соединяйте города из своих билетов. Незавершённые билеты вычитают очки в финале. Поле и игровые числа соответствуют классическому набору; модели, подложка и печать карточек созданы отдельно.

[Адрес опубликованной соло-версии](https://last-train-evacuation.pink-gecko-8072.chatgpt.site).

Ветка integration/europe-multiplayer добавляет локальные частные комнаты на 2–5 мест. Сервер запускается отдельно; статическая публикация сама не обслуживает комнаты. Сетевые сохранения находятся на сервере, обычная партия и обучение сохраняются отдельно в браузере.

Ветка `integration/europe-menu-technical` подключает принятую 3D-кассу с руками (`78c945e`) к этой сетевой основе (`c295bb4`). Главное меню запускает обычную партию, продолжение, отдельное обучение и игру с друзьями через прежние callbacks. Это промежуточная техническая интеграция: художественная приёмка открыта, аниматор остановлен; main и публикация не обновлены. Состав подключения и границы проверки описаны в [отчёте интеграции](docs/validation/europe-menu-technical.md).

Ветка `integration/europe-menu-common` переносит принятую общую сцену `a5911d6` поверх проверенной интеграции `16ae5df`. Renderer, сессия, игра и сеть сохранены; новый проход проверил меню, обычную партию, обучение, раздельные сохранения и WebGL. Границы и стенд описаны в [отчёте общей интеграции](docs/validation/europe-menu-common-a591.md).

[Репозиторий GitHub](https://github.com/onetaper-gleb/ticket-to-ride).

## Запуск

Нужны Node.js 22.12+ или 24 и pnpm 11.25.0.

    pnpm install --frozen-lockfile
    pnpm dev

Откройте http://127.0.0.1:5173. Сборка создаёт статическую папку dist/.

    pnpm check
    pnpm test
    pnpm format:check
    pnpm simulate --count 25
    pnpm build

## Локальная комната

Для сервера нужен Node.js 24.19.0+ с node:sqlite. Установите его отдельные зависимости и запустите в первом терминале:

    pnpm server:install
    pnpm server:start

Во втором терминале выполните `pnpm dev`, откройте http://127.0.0.1:5173 и выберите «Играть с друзьями». Создайте комнату и передайте ссылку приглашения второму клиенту. Перед запуском участники подтверждают готовность, свободные места ведущий может заполнить ботами. Микрофон при входе выключен.

По умолчанию сервер слушает только 127.0.0.1:8787 и хранит приватную SQLite базу в server/data/rooms.sqlite. Клиент использует этот адрес только на локальной HTTP странице. Для другого порта настройте `EUROPE_PORT`, `EUROPE_ALLOWED_ORIGINS` у сервера и `VITE_NETWORK_URL` у клиента. Vite читает параметры клиента при запуске или сборке; пример лежит в .env.example. `EUROPE_DB_PATH` задаёт отдельную базу для проверок.

    pnpm server:check
    pnpm network:smoke

Для внешнего доступа нужны отдельно настроенные HTTPS/WSS и разрешённый Origin. `VITE_NETWORK_ICE_SERVERS` принимает JSON-массив RTCIceServer; внешние STUN/TURN по умолчанию отсутствуют. Значения VITE-переменных входят в браузерную сборку, поэтому постоянные приватные credentials туда не помещают. Локальная проверка голосового mesh не подтверждает работу через произвольный NAT. Публичный сервер и платная инфраструктура автоматически не создаются.

## Первая партия

При первом входе выберите «Пройти обучение». Подсказки проведут от выбора билетов до первого занятого маршрута. Учебная и обычная партии сохраняются отдельно.

Слева лежат пять открытых карт и закрытая колода; снизу слева — билеты, снизу — рука, справа — лист действий. Направленный жест мыши по всей игровой области переключает выделенную опцию; более длинный жест на границе переводит фокус к соседней коллекции. Первый ЛКМ запрашивает захват мыши без игрового действия; следующий активирует выделенный предмет. Esc освобождает мышь. Меню открывается отдельной кнопкой. Небольшое движение даёт затухающий отклик камеры. Попадать курсором в поверхность карточки не требуется.

Пробел открывает поле с видимым курсором. Выберите маршрут или город, затем вернитесь к столу пробелом. На листе доступны цена, варианты оплаты и подтверждение. В руке можно отметить конкретные карты.

После одного действия нажмите «Завершить ход» на листе справа. До подтверждения соперники ждут, повторный добор недоступен. Второй добор, выбор новых билетов и доплата за тоннель продолжают начатое действие.
